# ReVinted-ProyectoFinal
Proyecto final de Paradigmas de Programación (iMAT, curso 2026/27). Videojuego de gestión desarrollado en Unity 6 que simula una tienda de segunda mano. Incorpora agentes de IA basados en máquinas de estados, IA de utilidad y aprendizaje por refuerzo (ML-Agents), con arquitectura orientada a objetos
